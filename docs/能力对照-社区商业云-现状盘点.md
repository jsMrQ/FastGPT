# Q（基于 FastGPT OSS）能力对照表

> 对照官方「社区版 / 商业版 / 云服务版」能力矩阵，盘点**当前本地定制版**实际具备情况。  
> 更新日期：2026-08-27  
> 说明：`✅ 有` = 当前可用；`🟡 部分` = 有入口/半套能力或依赖环境；`❌ 无` = 仍依赖商业版 Plus / 未落地。

---

## 总览结论

| 类别 | 结论 |
| --- | --- |
| 社区版标配能力 | 基本都有（工作流、分享链接/API、知识库、多模型等） |
| 你们已从商业版「抠」到 OSS 的 | **知识库索引增强**、**Agent 配置辅助生成**、**团队空间/部门成员**、**分享链接安全项**、**运行日志图表看板** |
| 仍明显缺的商业能力 | 应用评测看板、全渠道发布增强、远程工具调试、模型内容审核、SSO、多租户支付、完整管理后台 |
| 环境依赖（不是 Plus，但现在可能用不了） | **Skill / 虚拟机**（需 OpenSandbox）、**图片索引**（需 VLM）、**系统工具**（需导入 pkg） |

当前形态更接近：**社区版 + 少量商业能力本地化**，不是完整商业版。

## 7. 一句话对外口径

- **对同事**：通用知识库问答、工作流、分享链接/API、多模型、索引增强、Agent 辅助配置 —— **能用**。  
- **对领导**：不是完整商业版；评测看板、全渠道、SSO、强审核、远程工具调试 —— **还没有或不全**。团队权限、分享安全、运行日志看板已补齐可演示。  
- **对采购**：若只要内部知识库 + Agent，当前定制 OSS 够用；若要对齐商业版矩阵 80%+，评估买商业版或按上表逐项自研。
